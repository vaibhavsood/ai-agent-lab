## Learned

- RAG in `agent.py` is just: load the index at startup, a `search_notes` tool,
  and a prompt that says answer from the passages and cite them.
- I noticed the agent calls `search_notes` even for questions not in my notes.
  That's by design: it can't know what's in my files without searching.
- **Top-k search always returns k passages**, even irrelevant ones. Nothing in
  the code uses the similarity score. My off-topic question scored 0.477;
  relevant hits have been ~0.65-0.80.
- **Stage 06:** a schema + `response_format` makes the final answer JSON that
  code can rely on; it works together with tools. Code then checks every
  citation's quote against the actual file lines / PDF page. Failures go back
  to the model once.
- Thinking levels: `high` used ~2,000 tokens per question and was a few
  seconds slower, with no accuracy gain on lookup questions. All 18 citations
  verified at every level; "World Cup" was correctly marked not-in-notes.
