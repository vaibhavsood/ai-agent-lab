## Learned

- RAG in `agent.py` is just: load the index at startup, a `search_notes` tool,
  and a prompt that says answer from the passages and cite them. The loop
  itself has no RAG logic; the tool result lands in history and the model reads it.
- Indexing = find files -> chunk (bucket up to 800 chars, cut at headings once
  there are 300) -> embed (one vector per text, 90/min) -> save index.json.
- I noticed the agent calls `search_notes` even for questions not in my notes.
  That's by design: it can't know what's in my files without searching.
- **Top-k search always returns k passages**, even irrelevant ones. Nothing in
  the code uses the similarity score; only the model's reading decides.
  My off-topic question scored 0.477; relevant hits have been ~0.65-0.80.

## Important insight

A similarity threshold would turn "5 weak passages" into an explicit "not in
your notes", but the cutoff depends on the embedding model and should be
calibrated on known in/out questions (a small evaluation).
