## Learned

- `index.py` and `agent.py` are separate programs connected only by
  `index.json`: index once (slow, uses the embedding quota), then every
  question needs one quick embedding call plus a local comparison.
- `index.json` = a list of cards: source + lines/page, a copy of the text,
  and a 768-number vector of its meaning.
- There are two different `--root`s: `index.py --root` decides what's
  searchable; `agent.py --root` decides which files the tools can open.
- PDFs need text extraction (`pypdf`), per page, and are cited by page.
  Scanned PDFs have no text layer and would need OCR.
- What goes into the index shapes every answer (code outnumbers notes 141 to 59).
