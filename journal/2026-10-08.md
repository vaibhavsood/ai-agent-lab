## Learned

- Approval isn't a model feature. It's an `if` in `run_tool`, between the
  model's request and the tool running. The loop itself didn't change.
- A decline goes back as a normal `tool_result` (`is_error: true`), optionally
  with my reason, and the model adapts. The human becomes one more source of
  tool results.
- The path sandbox protects `write_file` but not `run_command`. For commands,
  approval is the only guard.
- Tool descriptions should state the environment (Windows `cmd.exe`, 60s
  timeout) so the model doesn't write Linux commands or start servers.
- Agents can be tested without a key by mocking: a fake `input()` played the human.
