## Learned

- `await` doesn't make the next line run early: inside one task, lines run in
  order. While a task waits, the event loop runs *other* tasks.
- A sub-agent is a tool whose function runs another agent loop.
- Each researcher starts with an empty history; only its report reaches the lead.
- Two-part question: the lead sent both parts in one step and they ran in parallel.

## Problem

1. Researchers kept searching until `max_steps` and returned nothing:
   159k tokens for one question.
2. Quotes got paraphrased between researcher and lead (3/6 citations verified).

## Fix

1. A budget in the prompt (at most 4 tool calls), and on the last step code
   asks for the report from what was found. Same question: 17k tokens.
2. The stage 06 citation check caught it; the lead re-delegated for exact quotes.

## Important insight

Multi-agent buys context isolation and parallelism, and costs tokens and
lost detail at every handoff.
