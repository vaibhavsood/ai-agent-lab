## Learned

- `remember()` is never called by name in the code: the model asks for it,
  and `TOOL_FUNCTIONS[name]` dispatches it. Adding a tool = function + schema
  + one table entry.
- When the model calls `remember` is its own judgment, shaped only by the
  tool description and system prompt.
- The folder limits what the agent can do, not what the model knows. General
  answers come from training data: no sources, possibly outdated.
- Gemini's usage report leaves function results out of input tokens.
- The newest free model was the slowest (queueing); one version older was ~15x faster.

## Problem

1. `gemini-3.8-flash` kept timing out.
2. Compaction never triggered (undercounted tokens).
3. One run hung overnight despite timeouts.

## Fix

1. Switched to `gemini-3.6-flash`, added `--model`.
2. Compaction uses our own ~4 chars/token estimate of the whole history.
3. Open. Hypothesis: the timeout is per chunk, not per call.

## Important insight

When a number looks wrong, design an experiment to find the truth instead of
guessing. Two of my guesses (thinking, tool-token field) were wrong; measuring found the real causes.
